Service Definition

Orpheus는 밴드부 운영진과 부원이 곡 정하기부터 공연 초대장까지 합주 운영을 한 흐름으로 관리하는 모바일 앱입니다.

음악 감상 앱이 아니라, 밴드부 운영이 실제로 흘러가는 순서를 앱 안에 담은 서비스입니다.

곡 정하기 파트 모집 일정 투표 합주실 예약 참석 응답 악보 공유 연습 확인 합주 기록 공연 준비 초대장 공유

Message Logic

핵심 메시지는 감정에서 시작해 해결로 이어진다.

Target
합주 준비를 관리해야 하는 밴드부 운영진과 참여해야 하는 부원
Problem
곡, 파트, 일정, 합주실, 참석, 악보, 연습 상태가 흩어져 있음
Solution
합주 준비 흐름을 모바일 앱 안에서 한 번에 관리
Value
운영진은 확인과 재공지 부담을 줄이고, 부원은 오늘 해야 할 일을 놓치지 않음
Message
합주 준비로 스트레스 받는다고? 여기서는 합주실부터 일정까지 전부 다 관리되는데!
