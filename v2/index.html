Orpheus. 03 / 11 · 타겟 정의
운영진 vs 부원

타겟별 메시지

A 운영진
  • 합주 인원 확인 · 파트 부족 확인
  • 일정 투표 관리 · 합주실 예약
  • 악보·연습 상태 확인
  • 셋리스트·공연 준비
운영진에게는
“이번 합주가 준비됐는지 한눈에 보세요.”
이럴 때 메시지를 만난다시험 끝나고 합주를 잡으며 단톡이 폭주할 때 — 합주실 포스터로 마주친다.
B 부원
  • 참석 여부 응답 · 일정 투표 참여
  • 내 파트 악보 확인
  • 연습 과제 제출 · 피드백 확인
  • 하고 싶은 곡 제안
부원에게는
“오늘 해야 할 일을 놓치지 마세요.”
이럴 때 메시지를 만난다합주실을 오가며 포스터·QR을 마주치거나, 장비를 사러 악기몰을 둘러볼 때.
Orpheus. 04 / 11 · 서비스 정의
What Orpheus Is

곡 선정부터 공연까지,
합주 운영을 한 흐름으로.

단순한 알림 앱도 아닙니다.
밴드부 운영이 실제로 흘러가는 순서를 그대로 앱에 담았습니다.

곡 정하기→ 파트 모집→ 일정 투표→ 합주실 예약→ 참석 응답→ 악보 공유→ 연습 확인→ 합주 기록→ 공연 준비
Orpheus. 05 / 11 · 메시지 도출 논리
How the Message Was Built
Target
합주 준비를 관리해야 하는 밴드부 운영진과, 그 과정에 참여해야 하는 부원
Problem
곡 · 파트 · 일정 · 합주실 · 참석 · 악보 · 연습 상태가 여러 채널에 흩어져 있음
Solution
합주 준비 흐름을 모바일 앱 안에서 한 번에 관리
Value
운영진은 확인·재공지 부담을 줄이고, 부원은 오늘 해야 할 일을 놓치지 않음
Message
합주 준비, 스트레스 받지 말자.
합주에 필요한 모든 걸 한 번에 관리!
왜 이 표현인가
01
기능이 아닌 감정에서
‘스트레스’는 밴드부가 실제로 쓰는 말 — 첫 문장을 공감으로 연다.
02
문제의 반대말로
흩어짐의 정반대인 ‘한 번에’로 해결을 즉시 약속한다.
03
명령형으로 끌어들여
‘받지 말자’로 청자를 함께 묶어 행동을 유도한다.

예뻐서 고른 문장이 아니라, 문제 구조에서 역산한 카피다.

Orpheus. 06 / 11 · Solution & Value

Solution & Value

화면 속 기능이 각자의 페인포인트를 어떻게 푸는지.

A 운영진
합주실 · 공연장 예약 + 합주실 리뷰 확인전화·사이트 돌며 예약하고, 검증 없이 고르던 일 제거
일정 투표 · 참석 응답 · 미응답 리마인드단톡으로 일정 잡고 참석 일일이 확인·재촉하던 일 제거
부족 파트 표시 · 인원 보강 촉구어느 파트가 비는지 막판에 파악하던 일 제거
악보 준비율 · 과제 · 회비 체크“다 됐어?” 반복 질문과 운영 잡무 감소
B 부원
오늘 할 일 (참석 · 악보 · 과제)단톡에 묻혀 내 할 일을 놓치던 일 제거
일정 투표 참여 · 내 파트 악보 공유투표·악보 링크를 찾아 헤매던 일 제거
연습 과제 · 피드백 확인피드백이 개인 메시지로 흩어지던 일 제거
프로필 레벨 (L1~L3)내 실력·성장을 보여줄 기준이 없던 일 해소

Where the Message Lands

어떻게 전달할까.

Orpheus. 10 / 11 · 수신자 경험 설계
Receiver Journey

인지에서 행동까지, 네 단계

01
인지
“합주 준비 스트레스, 딱 내 얘기네.”
02
이해
“곡·일정·합주실·악보를 한 앱에서 관리하는구나.”
03
신뢰
“운영진 홈·부원 홈이 실제 운영 흐름이랑 맞네.”
04
행동
“이번 합주 준비 현황, 한번 확인해보고 싶다.”
🛒악기몰 배너인지 → 행동장비를 사러 온 활동 밴드(새내기~고인물)에게 ‘Orpheus라는 해결책’을 각인시키고, 바로 다운로드로 잇는다.
📌합주실 포스터이해 → 신뢰 → 행동이미 겪는 사람에게 “내 얘기다”를 확인시키고, 실제 화면·QR로 설치까지 끌어낸다.

타겟 · 채널 · 톤 · 메시지가 모두 “흩어진 합주 준비를 한 번에” 한 방향을 가리킨다.
